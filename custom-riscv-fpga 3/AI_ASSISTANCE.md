# Where the project came from

This is here so a reader can tell which work was done personally and which parts were prepared with outside help.

- **Supplied starter archive:** Tang Nano 20K setup notes, basic FPGA LED-blink experiment, simple button example, an earlier build/programming log, photo of the FPGA kit packaging, and some initial C and repository files.
- **AI-assisted expansion (ChatGPT, October 25, 2026):** the RV32I processor RTL, system-on-chip connections, C/assembly acceptance programs, Python instruction interpreter, RTL testbench, CI workflow, and much of the explanatory writing.
- **Student's own work after receiving the package:** **not documented yet**. Record verified contributions and changes in [MY_WORK.md](MY_WORK.md) as they happen.

The original starter log reports loading a standalone LED-blink bitstream. That is different from showing the newer RISC-V processor working on the FPGA. The CPU has not been demonstrated on physical hardware as part of this package.

A strong project presentation should explain which decisions you made, which bugs you debugged, what you tested yourself, and how you know it works. Don't describe AI-generated source code as entirely handwritten, or claim test runs and board demonstrations that did not happen. Check each college's rules on AI-assisted portfolio work.
