# Primary references

- [RISC-V RV32I Base Integer ISA (ratified specification)](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html) — instruction encodings, signed arithmetic and alignment semantics.
- [Sipeed Tang Nano 20K](https://wiki.sipeed.com/hardware/en/tang/tang-nano-20k/nano-20k.html) — board resources; verify revision and pins against current schematic.
- [YosysHQ OSS CAD Suite](https://github.com/YosysHQ/oss-cad-suite-build) — portable FPGA tools.
- [Project Apicula](https://github.com/YosysHQ/apicula) — open-source Gowin FPGA bitstream and board support.
- [Icarus Verilog](https://steveicarus.github.io/iverilog/) — RTL simulation.
- [LLVM RISC-V target](https://llvm.org/docs/RISCVUsage.html) — Clang cross-compilation target and ISA flags.

These are external technical references, not evidence that local FPGA synthesis or hardware demonstration passed.
