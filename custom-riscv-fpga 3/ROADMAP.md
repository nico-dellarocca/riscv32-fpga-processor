# Things to do next

This is a to-do list, not a list of achievements.

- [ ] **Run the CPU Verilog simulation.** Install Icarus Verilog, run `make test`, and save the output.
- [ ] **Explain two instructions.** Pick something simple (`ADDI`) and something with memory (`LW` or `SW`), and trace what changes each clock cycle.
- [ ] **Fix or improve something personally.** For example, add a new test or make the GPIO behavior easier to observe. Record the problem and the solution in `MY_WORK.md`.
- [ ] **Build the FPGA bitstream.** Run `make soc` with the FPGA tools installed. Keep the area/timing report, including any errors.
- [ ] **Test it on the board.** Check pins and program the Tang Nano 20K. Film the CPU running the compiled LED program if it works.
- [ ] **Update the results page.** Add actual screenshots, waveforms, or links after the tests, without guessing.

Already available in the starter package: CPU/SoC code, C/assembly programs, Python reference-model checks, and a Verilog testbench. Those are prepared materials, not a record of independent student implementation or completed FPGA validation.
